# Inside Your Computer

Web recreation of the classic Microsoft Plus! 95 **Inside Your Computer** screensaver.

The web edition is a single self-contained `index.html` suitable for GitHub Pages. It includes the animation artwork and original saver sounds directly in the page, so there are no external asset files to manage.

## Controls

- Tap/click once to enable browser audio.
- **SOUND ON/OFF** toggles sound.
- **STOP** stops animation and audio.
- Controls fade after a few seconds and reappear on touch/click.

## Pacing

- 8 Hz 486-style simulation
- movement every second simulation tick
- 480-line logical height with widescreen expansion
- nearest-neighbor pixel rendering
- first sound after about 6 seconds
- later sounds about every 12–18 seconds
- no overlapping audio

## GitHub Pages

This repository is intended to publish `index.html` with GitHub Pages from the `main` branch.
